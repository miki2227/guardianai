# Observer-state diagnostic, declared after calibration 101

Development observation: the original Jev referee gave high unsupported-claim
scores to a qualified sender possibility statement and a correct receiver
deduction in calibration case 101. The state represented negative clues as a list
and did not state the speaker's knowledge boundary. This motivates a new variant;
it does not establish why the original judgment failed.

Keep all original scores. Compare them with role-aware grounding that supplies
deterministically derived public world facts, the speaker's initially visible
clue, available message history, and an explicit uncertainty-scope instruction.
Private faction values remain withheld. This is a combined prompt/state packaging
intervention; improvements cannot be attributed solely to one changed component.
No training occurs. Case 101 is development data and must not be called held out.
Cases 102 onward can test the frozen variant; keep failures and null effects.

The diagnostic is distinct from detecting misalignment. Correct case reasoning,
private-role disclosure, a wrong faction guess, and an emergent non-semantic
convention are separate labels. No convention claim follows from fewer referee
false alarms. Closest prior work includes epistemic runtime monitoring and
Auditable Belief Updates (Li et al., arXiv:2610.38869); epistemic grounding itself
is not claimed new. The contribution under test is the concrete evaluation of a
decision-model observer under asymmetric agent information in this system.
