## What can be claimed now

The implementation separates a rejected operation from task revocation and descriptor release. Its own earlier revisions exhibit retained counterexamples. Bounded corrections work for the tested syscall sequences and filter-installation routes. Actual software work exposes observer overflow and a false alarm, with both failures preserved. Shared context and receipts provide inspectable state provenance. These are bounded empirical and engineering findings.

The conditional lock/snapshot arguments explain the code's intended invariants under trusted-component assumptions. They are not mechanized end-to-end proofs or new general security theorems. The study does not establish that another system has the same defects.

## Remaining decision gates

1. Define a distinct contribution against close prior supervisor, capability and evidence-monitoring systems. Naming an existing mechanism or combining APIs is insufficient. The [15 November update](PRIOR_ART_UPDATE.md) adds guardscope, context-pipeline, ClawSentry and DelegateGuard comparisons and explicit rejection criteria; it does not establish novelty.
2. For the persistent-agent hypothesis, obtain a serving interface that exposes compatible retained-context accounting and reset/compaction semantics for the actual requested model. A logical thread counter is insufficient. Controlled truncation must be named as an intervention if used.
3. Evaluate the intended real workflow with appropriate scope, independent task streams and preserved null outcomes. Do not replace the user's request for useful system operation with more arbitrary probe volume.
4. Establish meaningful comparison scope and ground truth before making accuracy, recall or performance-superiority claims. Existing timing results have unmatched instrumentation.
5. Review compatibility restrictions, unknown observation gaps, already-released data and the historical false alarms as material limitations.
6. Select the target journal and provide author/submission details only when the contribution and evidence support that step. No submission or external publication has been performed.
